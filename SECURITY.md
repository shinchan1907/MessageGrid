# Security Policy

## Supported Versions

We actively monitor and patch vulnerabilities in the following version lifecycles:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

If you identify a security vulnerability inside this EspoCRM WhatsApp extension, **please do not open a public issue.** Instead, submit reports through one of these channels:

*   **Email**: security@yourcompany.com (Please encrypt your reports using GPG).
*   **PGP Public Key**: (Insert Key Signature Fingerprint here).

### Our Commitment
We will evaluate and reply to your report within **24 hours**, and aim to deliver a certified hotfix within **5 working days**.
